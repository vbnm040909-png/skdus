# 🐾 댕냥구조대

유기동물 보호소 정보를 기반으로, 이용자의 거주 지역·생활 루틴·반려동물 선택 기준에 맞춰 가장 잘 맞는 친구를 추천해주는 웹서비스입니다.

## 주요 기능

- **공공데이터 API 연동**: 농림축산검역본부 「유기동물 조회 서비스」 OpenAPI를 백엔드 프록시로 호출
- **맞춤형 매칭**: 지역, 주거형태, 활동량, 부재시간, 가족구성, 반려경험 등을 100점 만점 점수제로 매칭
- **즐겨찾기**: localStorage 기반, 관심있는 친구를 하트로 저장
- **공유 기능**: Web Share API (모바일에서 카카오톡 등으로 바로 공유) + 클립보드 복사 폴백
- **모바일 반응형**: 480px / 768px 브레이크포인트로 최적화
- **API 키 없이도 동작**: 키 미설정 시 16마리 샘플 데이터로 자동 폴백

## 폴더 구조

```
나연/
```

## 실행 방법

### 1. Node.js 설치 확인 (18 이상)

```powershell
node -v
```

### 2. 의존성 설치

프로젝트 폴더에서:

```powershell
npm install
```

### 3. (선택) 공공데이터 API 키 설정

[공공데이터포털 - 유기동물 조회 서비스](https://www.data.go.kr/data/15098931/openapi.do)에서 무료로 발급 후:

```powershell
$env:PUBLIC_DATA_API_KEY = "발급받은_키_여기에_붙여넣기"
```

> API 키 없이 실행해도 샘플 데이터(16마리)로 정상 동작합니다.

### 4. 서버 실행

```powershell
npm start
```

콘솔에 표시되는 주소(`http://localhost:3000`)를 브라우저에서 열면 됩니다.

## API 엔드포인트

- `GET /api/status` — API 키 설정 여부와 캐시 상태
- `GET /api/pets?region=서울&species=dog` — 유기동물 목록 조회 (10분 캐시)

## 사용된 기술

- **백엔드**: Node.js 18+, Express 4
- **프론트엔드**: 순수 HTML/CSS/JS (프레임워크 없음)
- **데이터**: 공공데이터포털 OpenAPI (`apis.data.go.kr/1543061/abandonmentPublicSrvc`)
- **저장**: 즐겨찾기는 브라우저 localStorage

## 매칭 알고리즘 요약

기본 50점에서 시작해서:

- **지역 일치** +15
- **활동량 일치** +12
- **선호 우선순위 항목별 일치** +7 (중복 가능)
- **아이 친화 (가족에 어린이 있을 때)** +10
- **원룸 + 대형견** −15 (부적합 페널티)
- **초보자 + 특수 케어 필요** −12

상위 12마리를 매칭 점수 순으로 표시하며, 각 카드에 **잘 맞는 점**과 **고려할 점**이 함께 노출됩니다.
